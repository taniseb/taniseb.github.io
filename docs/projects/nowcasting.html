The Question

Brazil’s official inflation index (IPCA) is released monthly by IBGE, typically 10–15 days after the reference period ends. During this window, policymakers, investors, and researchers are flying blind.

Can machine learning models predict the IPCA release before it happens — and beat a simple autoregressive baseline?

This is called nowcasting — estimating economic variables in real time using a mix of early-release indicators and alternative data.

Why this matters

The Banco Central do Brasil (BCB) sets the SELIC rate based partly on inflation expectations. If you can nowcast inflation more accurately, you can:

  • Better anticipate monetary policy decisions
  • Price fixed income instruments more precisely
  • Understand which sectors are driving inflationary pressure in real time

Data sources

Source Variables Frequency
BCB API (SGS) SELIC, exchange rate, M2, credit Daily / Monthly
IBGE IPCA components, IPCA-15 (advance) Monthly
Google Trends Search terms correlated with prices Weekly
CEPEA Commodity prices (agriculture) Daily
FGV IGP-M, IPC-BR (early releases) Monthly 
# Pulling data from BCB API with python-bcb
import bcb
from bcb import sgs

# IPCA monthly (series 433)
ipca = sgs.get({'ipca': 433}, start='2010-01-01')

# SELIC target (series 432)
selic = sgs.get({'selic': 432}, start='2010-01-01')

print(ipca.tail())

Methods

Three models are compared against a simple AR(12) baseline:

1. LASSO regression — penalized linear model that selects the most relevant predictors from a large feature set. Interpretable and fast.

2. XGBoost — gradient boosted trees. Handles non-linearities and interactions between indicators without feature engineering.

3. LSTM — long short-term memory neural network. Captures temporal dependencies that tabular models may miss.

Baseline: AR(12) — autoregressive model using 12 lags of IPCA. The benchmark to beat.

Evaluation

Models are evaluated with an expanding window cross-validation — mimicking real-time forecasting:

  • Train on data up to month t
  • Predict month t+1
  • Roll forward one month at a time

Metrics: RMSE, MAE, directional accuracy (did the model get the sign of change right?).
